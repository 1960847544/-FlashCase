# 闪匣 FlashCase

一个没有广告的 Flash / 网页游戏大厅。

49 / 86 / 100 三内核自动适配，让洛克王国、赛尔号、小花仙、4399、7k7k
这些老页游在 2026 年还能打开。

> 不是广告大厅，是一个装游戏的匣子。

> 本仓库仅发布 Windows 安装包，不提供源代码。

## 下载

到 [Releases](../../releases) 下载最新版安装包。

- 系统：Windows 10 / 11 x64
- 依赖：.NET Framework 4.7.2+、VC++ 2015-2022 x64
- 安装包未签名，Windows 可能提示 SmartScreen，请核对 SHA256 后运行

## 为什么做这个

传统游戏大厅越来越像资讯站：弹窗、广告位、捆绑推荐。  
但老页游玩家真正需要的只是：

- 一个能打开 Flash 的浏览器
- 一个自己的游戏库
- 不要广告，不要后台常驻

闪匣只保留这些。

## 功能

- 无广告、无弹窗、无捆绑、无遥测
- 49 / 86 / 100 三内核，按页面切换
- Flash 游戏自动启用插件，WebGL2 页面切 100 内核
- 游戏封面墙、分类、搜索、收藏
- 小号多开，独立缓存不串号
- 自定义壁纸、深色界面、高帧率
- 本机硬件参数页
- 游戏库、设置、缓存全部保存在本地

## 三个内核

| 内核 | 适合 | Flash | WebGL2 |
|---|---|---|---|
| 49 | 老页游兼容 | ✅ | 有限 |
| 86 | Flash 主力 | ✅ | ✅ |
| 100 | 新 WebGL2 页面 | ❌ | ✅ |

> Flash 游戏请用 86 内核；100 内核不支持 Flash。
